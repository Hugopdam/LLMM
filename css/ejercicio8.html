enlace 1: Posicionamiento absoluto (position: absolute;): Esta propiedad permite colocar un elemento en una posición específica dentro de su contenedor con position: relative;. Los elementos con position: absolute; se posicionan en relación al contenedor más cercano que tenga position: relative;. Si no hay tal contenedor, se posicionan en relación al elemento .​ Propiedades de posición (top, left, right, bottom): Estas propiedades determinan la ubicación exacta de un elemento posicionado absolutamente dentro de su contenedor. Por ejemplo, top: 10px; left: 20px; coloca el elemento a 10 píxeles desde la parte superior y 20 píxeles desde la izquierda del contenedor.​ Propiedad z-index: Esta propiedad controla el orden de apilamiento de los elementos posicionados. Un elemento con un z-index mayor se superpone a otro con un z-index menor.​ Propiedad overflow: Controla cómo se muestra el contenido que excede el área de un elemento. Puede tomar valores como visible, hidden, scroll o auto.​ Propiedad clear: Utilizada para controlar el flujo de los elementos flotantes, especificando en qué lados de un elemento no deben flotar otros elementos.​ Estas propiedades combinadas permiten un control preciso del diseño y la disposición de los elementos en la página, logrando una presentación efectiva de las "Seis leyes de Murphy". enlace 2: Posicionamiento absoluto (position: absolute;): Esta propiedad permite colocar elementos en posiciones específicas dentro de su contenedor.
