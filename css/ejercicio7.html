enlace 1: Posicionamiento flotante con float: La propiedad float permite que un elemento se alinee a la izquierda o derecha dentro de su contenedor, permitiendo que el contenido siguiente fluya a su alrededor. En este ejercicio, se utiliza el pseudo-elemento ::first-letter para estilizar la primera letra de cada párrafo, aplicándole un tamaño de fuente mayor y flotándola a la izquierda. Esto crea un efecto de letra capital, donde la primera letra sobresale y el texto restante se ajusta alrededor de ella. Propiedad clear: La propiedad clear se utiliza para controlar el flujo de los elementos flotantes, especificando en qué lados de un elemento no deben flotar otros elementos. Aunque en este ejercicio específico no se emplea clear, es común utilizarla para evitar que elementos posteriores se ajusten alrededor de elementos flotantes anteriores. Modelo de caja y márgenes: Cada elemento en CSS se representa como una caja que consta de márgenes, bordes, relleno y contenido. En el ejercicio, se ajustan los márgenes de los párrafos para controlar el espacio alrededor de ellos y asegurar una separación adecuada entre las citas. Propiedad overflow: La propiedad overflow controla cómo se muestra el contenido que excede el área de un elemento. En este contexto, se utiliza para manejar el contenido que podría desbordarse debido al posicionamiento flotante de la primera letra, garantizando que el diseño se mantenga consistente y sin superposiciones inesperadas.
