Example 1: Changing Text Color

This example shows how to change the color of text using the `color` property in CSS.

/* CSS */
.colored-text {
    color: red;
}

Preview:

This text is red!

Example 2: Centering Text and Styling a Box

This example demonstrates how to center text within a box and apply background color and border radius.

/* CSS */
.centered-box {
    text-align: center;
    padding: 20px;
    background-color: lightblue;
    border-radius: 5px;
}

Preview:

Centered content inside a styled box.

Example 3: Adding a Hover Effect

This example applies a hover effect that changes the text color when you hover over it.

/* CSS */
.hover-effect {
    color: black;
    transition: color 0.3s ease;
}
.hover-effect:hover {
    color: green;
}

Preview:

Hover over this text to see the color change!

Example 4: Adding a Shadow to a Box

This example demonstrates how to add a shadow to a box using the `box-shadow` property.

/* CSS */
.shadow-box {
    width: 150px;
    height: 150px;
    background-color: lightcoral;
    box-shadow: 5px 5px 15px rgba(0, 0, 0, 0.5);
}

Preview:

Example 5: Creating a Gradient Background

This example demonstrates how to use the `linear-gradient` property to create a gradient background.

/* CSS */
.gradient-box {
    width: 100%;
    height: 100px;
    background: linear-gradient(to right, red, yellow, green);
    border: 1px solid #ddd;
}
