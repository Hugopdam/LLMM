Example 4: Creating a Table

<table border="1">
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>John</td>
    <td>30</td>
  </tr>
</table>

Result:

Name Age
John 30

Example 5: Creating an Ordered List

<ol>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ol>

Result:

  1. Item 1
  2. Item 2
  3. Item 3
